# Shepot

Голосовой ввод для Mac. Говорите — текст появляется там, где стоит курсор, в любом приложении.
Распознавание — модели Whisper через [WhisperKit](https://github.com/argmaxinc/WhisperKit), всё работает на устройстве: без облака, подписок и сетевых запросов (кроме скачивания моделей по кнопке).

- Живёт в строке меню, без иконки в Dock.
- Запись по сочетанию клавиш (по умолчанию ⌥ Space), правому ⌘ или правому ⌥: удерживать или «нажать-нажать».
- Текст вставляется в активное окно через буфер обмена и ⌘V, прежнее содержимое буфера восстанавливается.
- Островок во время записи — снизу экрана или из чёлки, с волной, выбором модели, языка и историей.
- История 10 последних диктовок. Голос не сохраняется никогда.
- Модели: large-v3-turbo (рекомендуется), medium, small, large-v3. Хранятся в `~/Library/Application Support/Shepot/Models`.
- Языки: русский (по умолчанию), английский, автоопределение.
- Онбординг при первом запуске, автозапуск при входе.

**Требования:** Mac на Apple Silicon (M1 и новее), macOS 13+. Intel-маки не поддерживаются: сборка только под arm64, а без Neural Engine модели работали бы слишком медленно.

**Раньше приложение называлось Dictate.** При первом запуске Shepot сам переносит скачанные модели, настройки и историю. Права macOS (микрофон, «Универсальный доступ») привязаны к старому имени, поэтому их нужно выдать заново — проведёт окно приветствия. Старый пункт Dictate в «Объектах входа» и в «Универсальном доступе» можно удалить.

## Установка (для друзей)

1. Получите файл `Shepot-<версия>.dmg` и откройте его.
2. Перетащите **Shepot** на ярлык **«Программы»** в окне образа.
3. Запустите Shepot из «Программ». macOS предупредит, что не может проверить разработчика — нажмите **«Готово»** (не «В корзину»).
4. Откройте ** → Системные настройки → Конфиденциальность и безопасность**, внизу у сообщения про Shepot нажмите **«Всё равно открыть»** и подтвердите. Это нужно один раз.
5. Дальше проведёт окно приветствия: микрофон → «Универсальный доступ» → скачивание модели → выбор клавиши.

> Почему предупреждение: приложение подписано личным сертификатом, а не платным Apple Developer ID, и не проходило нотаризацию Apple. Для приложений «для себя и друзей» это нормально.

Та же инструкция лежит внутри образа в файле «Как установить.txt».

### Права macOS

| Право | Зачем | Где включить |
|---|---|---|
| Микрофон | запись голоса | спросит само при первой записи |
| Универсальный доступ | вставка текста (⌘V) и правые ⌘/⌥ | Системные настройки → Конфиденциальность и безопасность → Универсальный доступ |

Input Monitoring не нужен.

### Если что-то не так

- **Текст копируется, но не вставляется** — нет «Универсального доступа». Если Shepot в списке уже включён, удалите его «−», добавьте «+» и перезапустите приложение.
- **Первая диктовка долго распознаётся** — macOS один раз компилирует модель под Neural Engine (1–3 минуты).
- **Клавиша не срабатывает** — сочетание может быть занято другим приложением (Spotlight, Superwhisper и т. п.). Смените в меню Shepot → Настройки.

### Удаление

Выйдите из Shepot, удалите `Shepot.app` из «Программ» и папку `~/Library/Application Support/Shepot` (модели, до нескольких ГБ).

## Разработка

### Структура

```
Shepot/
  ShepotApp.swift            точка входа, иконка в строке меню
  AppState.swift              состояние: триггер → запись → распознавание → вставка, настройки
  History.swift               история диктовок
  Permissions.swift           микрофон и «Универсальный доступ»
  Audio/Recorder.swift        запись 16 кГц моно в память + уровень громкости
  Transcription/Transcriber.swift   обёртка над WhisperKit, одна загруженная модель
  Models/ModelStore.swift     каталог моделей, скачивание и удаление
  Input/HotKey.swift          глобальное сочетание (Carbon)
  Input/ModifierTrigger.swift правый ⌘/⌥ как отдельная клавиша
  Input/Paster.swift          буфер + ⌘V + восстановление буфера
  UI/Overlay.swift            островок (снизу / из чёлки)
  UI/IslandControls.swift     пилюли и выпадающие списки островка
  UI/MenuPanel.swift          панель из строки меню
  UI/Onboarding.swift         приветствие при первом запуске
  UI/HotKeyWindow.swift       запись нового сочетания
  UI/Theme.swift              цвета и общие элементы
scripts/
  install.sh                  собрать и установить себе в /Applications
  make-dmg.sh                 собрать DMG для друзей → dist/
  make-icon.swift             генератор иконки
```

Единственная зависимость — WhisperKit (Swift Package Manager).

### Сборка

Нужен Xcode 16+ (проект использует синхронизируемые папки).

```bash
open Shepot.xcodeproj        # ⌘R — запуск из Xcode
scripts/install.sh            # Release в /Applications
scripts/make-dmg.sh           # dist/Shepot-<версия>.dmg для раздачи
```

### Подпись

Проект подписывается локальным сертификатом **«Dictate Local»** — имя осталось с прежнего названия. Создаётся так: Связка ключей → Ассистент сертификации → Создать сертификат, тип «Подпись кода», «Собственный корневой». Постоянная подпись нужна, чтобы macOS не сбрасывала права при каждой пересборке.

Чтобы собрать на другом Mac: создайте сертификат с тем же именем или поменяйте `CODE_SIGN_IDENTITY` в настройках таргета (`-` = «Sign to Run Locally», но тогда права будут слетать после каждой сборки).

Версия приложения — `MARKETING_VERSION` в настройках таргета; она же попадает в имя DMG.
